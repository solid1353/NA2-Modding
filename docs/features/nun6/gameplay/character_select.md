# NUN6 Character Select reference

NUN6 prepends No Support ID `0x25` to the unchanged native support list and
raises the population bound from 33 to 34 entries. Its BTL compatibility helper
also extends the accepted support-ID range through `0x25`.

This establishes an additive implementation model for the NA228
[support-selection feature](../../character_select.md#support-selection). It
does not supply artwork: NA228 uses the official NUN5 Leaf sprite and its own
resident-font label.
