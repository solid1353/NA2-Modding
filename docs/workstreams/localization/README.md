# Localization

Umbrella workstream for tasks from Font, UI Translation, and String Translation.

## Workstream policy

- The Localization coordinator may take any user-selected task from the Font, UI Translation, or String Translation workstreams.
- By default, Localization performs the work itself.
- Localization may always ask its Font, UI Translation, and String Translation child workstreams for information when necessary.
- A `del:` prefix permits, but does not direct or recommend, Localization to delegate work to its Font, UI Translation, and String Translation child workstreams when Localization determines delegation is necessary.
