# Bugs

Coordination-only tracker for known defects. Implementation remains in the
workstream that owns the affected behavior.

## Workstream policy

- `TASKS.md` is the canonical bug list.
- The `Bugs` subsection always remains under `Backlog`. Selecting, routing, or
  fixing an entry never moves the subsection to another status.
- Prefix every bug with a bold workstream label such as `**Font:**`.
  Use `**Shared:**` for confirmed cross-workstream defects and `**Unknown:**`
  until ownership is established.
- This workstream records, deduplicates, classifies, and routes bugs. It does
  not investigate or implement fixes.
- A bug is fixed only in its owning workstream after the user selects it and
  approves that task's plan.
