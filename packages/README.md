# Package History

Keep active workflow packages here so builds do not depend on the user's
Downloads folder and prior packages remain available through Git history. This
includes packages generated by Codex or project scripts as well as downloaded
or imported inputs.

- Use unique filenames and never overwrite an older package. When a package has
  a `vNN` version, place it after the `YYYYMMDD_HHMMSS` timestamp.
- `NA2_APPLY__<TYPE>__*.zip` files are selected by the build workflow.
- `NA2_APPLY__TRANSLATION__*.tsv` files are selected for translation patches.
- `NA2_translation_package_builder*.zip` files are selected by `na2 ub`.
- Builder and generated translation versions are not pinned here. The workflows
  select the newest available inputs; inspect the installed builder and latest
  generated run before reporting a version as current.
- Copy explicitly accepted frozen references to `milestones/packages/`; ordinary
  package history stays here.
